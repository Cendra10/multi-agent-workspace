# Multi-Agent Workflow

## Description
A simple multi-agent workflow built with LangGraph, where a planner creates a task plan and a worker executes it.

## Tech Stack
- Python
- LangGraph
- Groq API
- OpenAI Python SDK

## Installation
1. Create and activate a Python virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Create a `.env` file and add your Groq API key: `GROQ_API_KEY=your_api_key`.
